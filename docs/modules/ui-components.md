# UI 组件模块 (`components/`)

TTab 的 UI 兼具高度的功能性和极佳的视觉表现力。

## 1. 核心视图控制器 (`BookmarkList.tsx`)

这是整个应用的主控组件。

### 交互功能
- **搜索状态感知**: 
  - **视觉反馈**: 搜索时图标呈现脉冲动画，面包屑导航自动淡出以减少视觉干扰。
  - **路径提示**: 搜索模式下，磁贴项 (`TileItem`) 和标签项会显示其所属的父文件夹名称。
  - **空状态**: 提供了带有动画的“未找到搜索结果”反馈界面。
- **拖拽排序**: 集成了 `@dnd-kit`。搜索模式下自动禁用，以保护原始书签结构。
- **上下文菜单**: 右键触发 `ContextMenu`，支持重命名、删除和打开，完全集成 i18n。


### 属性增强 (`useMemo: enrichedItems`)
- **动态尺寸**: 根据书签索引自动分配 `small`, `medium`, `wide`, `large` 四种尺寸。
- **动态权重**: 生成随机或基于索引的权重值，用于标签云展示。

## 2. 展示模式对比

### 平铺模式 (`TileItem.tsx`)
- **网格布局**: 使用 CSS Grid (`grid-auto-rows`, `grid-flow-dense`) 实现类似 Pinterest 的紧凑布局。
- **毛玻璃效果**: 结合 `backdrop-blur` 和 `bg-white/5` 营造深空感。
- **交互**: 悬停时触发比例缩放和亮度增强。

### 标签模式 (`TagItem.tsx`)
- **云状布局**: 采用 `Flexbox` 自动折行对齐。
- **个性化上色**: 根据提取的 `themeColor` 动态设置文字颜色或背景阴影。
- **动态旋转**: 根据设置，标签会随机产生小角度旋转 (`allowRotation`)。
- **权重感知**: 标签大小受 `weight` 影响，突出频繁访问的视觉重点。

## 3. 设置面板 (`SettingsPanel.tsx`)

- **自定义壁纸管理**: 支持用户上传本地图片。系统自动处理 Base64 转换、上传状态反馈及文件大小校验（4MB 限制）。
- **实时反馈**: 更改设置后，通过 `storage.updateSettings` 保存，并调用 `onRefresh` 通知主视图更新状态。
- **完全国际化**: 接入 `i18n` 系统，所有按钮标签、设置项描述、模态框占位符及错误提示均支持即时语言切换。
- **分类管理**: 将视觉、布局、行为设置清晰划分为不同板块。
