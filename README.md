# TTab - 灵动书签仪表盘 🚀

[![Build and Release Extension](https://github.com/TextlineX/TTab/actions/workflows/release.yml/badge.svg)](https://github.com/TextlineX/TTab/actions/workflows/release.yml)

TTab 是一款基于 Vite + React 开发的高性能、高交互浏览器插件。它不仅是一个书签管理器，更是一个充满工业美感与艺术气息的个人仪表盘。

## ✨ 0.7 新增：云端、同步与整理修复

- **云服务（可选）**：项目里的 `server/` 是一个零依赖的小服务器（Node 18+，见 `server/README.md`），提供账号、跨浏览器同步和社区标签。不部署它，TTab 照样完整可用。
- **跨浏览器同步**：设置 → 云端与同步。登录同一个账号，Edge / Chrome 之间的标签和组合自动一致（按网页、按组合比较修改时间；删除也会同步）。
- **没有 AI 也能被「云端纠正」**：大家给同一个网页打的标签会汇总成共识；可手动「比对」看建议后再应用，也可打开「新书签自动比对」。只上传网址的哈希和你亲手打的标签，随时可收回，可关闭。三个云端开关默认全部关闭。
- **浏览器自带同步**：可选，用 Edge / Chrome 账号同步外观和首页设置（不含密钥）。
- **修复「移动书签无效 / 文件夹位置不变」**：文件夹按 id 建树（同名文件夹不再合并、空文件夹也显示）；右键文件夹可重命名、移动、上移下移、置顶、新建子文件夹，都能撤销；移动没有效果时会明确提示。
- **更快**：5000 个书签的首次规则打标签从 4.2 秒降到 0.09 秒。

## ✨ 0.6 新增：界面重做

- **分类总览**：左侧是完整的分类导航（浏览、我的组合、自动分组、推荐组合、文件夹树、标签），主区域用瀑布流把每个分类都展开显示，不再挤在一行里；点任何分类进入专注视图，可排序、切换卡片 / 列表 / 图标三种显示。
- **主题色**：深色 / 浅色 / 跟随系统；7 种强调色、自定义颜色，或从壁纸自动取色；所有文字颜色自动保证对比度。
- **背景**：极光（由强调色生成、缓慢流动）、纯色、图片（预设 / 上传 / 网址）、必应每日一图；图片可调模糊和遮罩。
- **选择器**：统一的下拉选择（支持拼音搜索、键盘操作）、文件夹选择器（树形、可搜索、显示数量）、开关、复选框、分段选择。
- **动效**：弹窗、抽屉、菜单、卡片筛选、侧边栏指示器都使用同一套弹簧参数；跟随系统的"减少动态效果"。
- **右键菜单**：卡片右键可打开、后台打开、编辑标签、复制链接、移动到文件夹、选择、删除；多选后可批量移动到文件夹。
- **设置**：大弹窗 + 左侧分区（外观、AI 助手、语义向量、智能推荐、数据、经典视图、快捷键）。
- 自定义小组件会自动跟随主题色和深浅色（见 `docs/widgets.md`）。

## ✨ 0.5 新增：自动整理与小组件

### 自动整理书签
- **一键整理**：首页出现"整理 N 个散落的书签"时点一下，自动把散落在收藏夹栏、其他收藏夹根目录的书签归入最合适的已有文件夹；剩下同一主题的书签（≥3 个）新建主题文件夹。
- **先预览再执行**：按目标文件夹列出每个书签和理由（内容相近、共同标签、与文件夹名匹配），可以逐个取消；可选"也检查放错的"和"AI 规划"。
- **完整撤销**：每次整理都有记录，撤销时按原来的位置还原顺序，并删除新建的空文件夹；之后手动移动过的书签不会被撤销动到。
- **新收藏自动归类**（设置 → 智能推荐，默认关闭）：新书签如果很明显属于某个已有文件夹，8 秒后自动放进去，可在整理记录里撤销。

### 小组件
- 首页新增小组件区：网页搜索（必应/百度/Google…）、待办、便签、常用网站、时钟（可设时区）、倒计时、天气（Open-Meteo，免费无需 Key）。
- 点"编辑"可以添加、拖动排序、切换尺寸（小/中/大/通栏）、设置、删除。
- **自定义小组件**：在"小组件工作室"里用 HTML/CSS/JS 编写，实时预览，保存即可使用；可以导出 `.ttwidget.json` 分享，导入时先列出权限再确认。
- 自定义小组件运行在**沙箱**里：不能直接联网、不能访问浏览器扩展接口，只能通过 `ttab` 接口按声明的权限读取书签、打开网页、保存数据、访问指定域名。
- 开发文档见 [docs/widgets.md](docs/widgets.md)。

## ✨ 0.4 新增：语义向量

- **相关网页更准**：网页详情里的"相关网页"同时参考标签和内容相似度，没有共同标签也能找到。
- **自动分组**：按内容把相近的网页自动分组（如"大模型 + AI 对话""设计灵感"），一键整组打开或保存为组合。
- **意思相近搜索**：搜索结果下方显示"意思相近的网页"，关键词对不上也能找到；没有关键词结果时回车直接打开第一个相近的网页。
- **两种模式**（设置 → 语义向量）：
  - 仅本地（默认，免费）：基于标题、简介、标签的用词计算，不调用任何接口。
  - 向量接口（更准，能理解意思）：硅基流动（bge-m3）、通义千问、智谱、OpenAI、Gemini、Ollama 本地。后台增量生成，只处理新增和变化的网页；与 AI 助手同一家服务商时自动复用 Key。DeepSeek、Claude、Kimi 暂无向量接口。

## ✨ 0.3 新增

- **地址栏搜书签**：在地址栏输入 `t` 再按空格，直接搜索书签，支持 `#标签` 和拼音；不输入关键词时列出此刻最常用的网页。
- **右键收藏**：在网页或链接上右键“收藏到 TTab”，自动打标签；配置了 AI 会补充更准确的标签和简介。
- **参考浏览历史**（设置 → 智能推荐，需要授权）：按最近 90 天的真实访问次数排序“常用”，并按工作日/周末 × 时段推荐“此刻常用”。只在本机计算。
- **完整拼音搜索**：覆盖 6763 个常用汉字，支持全拼、首字母、混合输入（`zhihu`、`zh`、`zhih` 都能搜到“知乎”），多音字任一读音都能匹配。
- **AI 打标签更准**（设置 → 智能推荐，需要授权）：打标签前读取网页的标题和简介；用户删除过的标签会告诉 AI 不要再给。

## ✨ 0.2 新增：智能视图

打开新标签页默认进入「智能」视图（左上角可切回原来的「文件夹」磁贴视图）。

- **一个网页多个标签**：首次打开自动按域名、标题、所在文件夹打上标签，不需要 AI；可手动增删，手动删掉的标签不会被自动加回来。
- **标签关系**：选中一个标签，旁边会出现与它相关的标签，颜色越实关联越强，点一下继续缩小范围；支持"且 / 或"切换。
- **推荐组合**：自动发现经常一起出现的标签组合（如"前端 + 文档"），一键筛选、一键整组打开（自动放进同一个标签组），也可以保存成「我的组合」。
- **智能视图**：常用、最近添加、未打标签、重复书签。
- **指令栏**：输入即搜索，支持 `#标签`、`-#标签`、`site:域名`、拼音首字母；回车直接打开第一个结果；`/` 随时聚焦。
- **AI 助手（可选）**：在设置里选择 DeepSeek / 通义千问 / 智谱 / Kimi / Claude / OpenAI / Gemini / Ollama 并填写 API Key 后：
  - 批量为书签打标签并写一句话简介；
  - `Ctrl + Enter` 用一句话让 AI 操作，例如"按使用场景生成几个组合""把设计相关的整理一下""打开我写前端常用的网站"；
  - AI 只会给出操作预览，勾选确认后才执行；会改动浏览器书签的操作默认不勾选；可撤销。
- **多选批量操作**：Shift + 点击或卡片左上角圆点多选，批量加标签、存为组合、全部打开、交给 AI。
- **Edge / Chrome 互通**：设置 → 标签数据 → 导出 / 导入，按网址合并标签和组合。
- 收藏网页（工具栏按钮）时会推荐标签。

详见 [docs/modules/smart.md](docs/modules/smart.md)。

## ✨ 核心特性（文件夹视图）

### 🧱 Windows 10 磁贴模式 (Start View)
- **砖墙式拼合**：采用严格的 12 列网格算法，支持 1x1, 2x2, 4x2, 4x4 多种磁贴尺寸，像砌砖墙一样严丝合缝。
- **Metro 工业美感**：彻底直角化、纯色块填充、大图标小标题，完美复刻 Windows 经典设计。
- **智能色彩引擎**：根据图标颜色自动计算背景色，并具备“三段式”对冲算法，确保任何图标都能清晰显示。

### ☁️ 灵动词云模式 (Cloud View)
- **有机权重布局**：标签根据权重（随机或文件夹深度）自动调整字号，形成中心放射状的有机布局。
- **艺术级视觉**：支持随机旋转、毛玻璃模糊以及纯文字模式，将书签转化为跳动的现代艺术品。

### 🛠️ 深度自定义控制
- **Workspace Root**：可以自由指定书签树的任何一个文件夹作为插件的“根目录”。
- **动态容器**：支持自由调节最大显示列数（4-16列）以及容器总宽度。
- **视觉主题**：内置多种高清壁纸，支持实时切换背景与粒子特效。

### ⌨️ 硬核交互体验
- **丝滑拖拽**：集成 `@dnd-kit`，支持磁贴的自由排序与位置同步。
- **右键菜单**：精致的磨砂质感菜单，支持重命名（毛玻璃对话框）、删除、进入文件夹。
- **多语言支持**：原生集成 i18n 系统，支持中文与英文自动匹配。

## 📦 安装与开发

### 直接安装 (推荐)
1. 前往 [Releases](https://github.com/TextlineX/TTab/releases) 下载最新的 `ttab-extension.zip` 并解压。
2. 打开 Chrome 或 Edge 的扩展程序页面 (`edge://extensions/`)。
3. 开启“开发人员模式”。
4. 点击“加载解压后的扩展程序”，选中解压出的文件夹。

### 本地开发
```bash
# 克隆项目
git clone https://github.com/TextlineX/TTab.git

# 安装依赖
pnpm install

# 启动开发环境
pnpm dev

# 编译打包
pnpm build

# 运行核心逻辑测试
pnpm test
```
